# RW_3.4: Emotional Nudge (Micro-Tasks) — Implementierungs-Spec

## Approval

- [ ] Approved

## Purpose

Bei chronisch verschobenen Tasks (rescheduleCount >= 3) einen visuellen Blockade-Marker anzeigen und einen "Nur 2 Minuten anfangen" Micro-Sprint anbieten. Ziel ist es, Prokrastinations-Muster zu durchbrechen: Der User startet etwas Kleines — mit der Option danach weiterzumachen oder normal zu beenden.

## Akzeptanzkriterien (aus Story-Spec)

- [ ] Tasks mit rescheduleCount >= 3: visueller Blockade-Marker
- [ ] Beim Oeffnen (TaskDetailSheet): Inline-Vorschlag "Nur 2 Minuten anfangen"
- [ ] Tap startet Mini-Sprint (2 Min via startImmediate)
- [ ] Nach 2 Min: "Weitermachen?" — Ja verlaengert, Nein beendet normal
- [ ] Nudge-Texte: statische Liste (min 10 Varianten), abwechselnd
- [ ] Max 1 Nudge pro Tag pro Task, max 3 Nudges pro Tag gesamt

## Implementation Details

### 1. EmotionalNudgeService.swift — CREATE

Stateless struct mit static methods. Kein SwiftData — Daily-Tracking laeuft ueber AppSettings (UserDefaults).

```swift
import Foundation

struct EmotionalNudgeService {

    // MARK: - Statische Nudge-Texte (min. 10 Varianten)

    private static let nudgeTexts: [String] = [
        "Nur 2 Minuten. Einfach anfangen.",
        "Du musst es nicht fertig machen. Nur starten.",
        "2 Minuten — dann entscheidest du.",
        "Der erste Schritt ist der schwerste.",
        "Kurz reinschauen kostet nichts.",
        "Starte. Alles andere kommt danach.",
        "2 Minuten Fokus. Mehr nicht.",
        "Du hast das schon oefter aufgeschoben. Heute anders?",
        "Klein anfangen ist besser als gar nicht anfangen.",
        "Mach einfach kurz auf — du kannst jederzeit aufhoeren.",
        "Nur schauen, wo du gerade stehst."
    ]

    // MARK: - Public API

    /// Prueft ob fuer diesen Task heute ein Nudge angezeigt werden darf.
    /// Bedingung: rescheduleCount >= 3, max 1 Nudge/Task/Tag, max 3 Nudges/Tag gesamt.
    static func canShowNudge(for taskID: String) -> Bool {
        let settings = AppSettings.shared
        resetIfNewDay()

        // Daily-Gesamtlimit
        guard settings.nudgeDailyCount < 3 else { return false }

        // Task-spezifisches Limit (heute schon genudget?)
        let alreadyNudged = settings.nudgeTaskIDs
            .split(separator: ",")
            .map(String.init)
            .contains(taskID)
        return !alreadyNudged
    }

    /// Gibt einen rotierenden Nudge-Text zurueck.
    static func nudgeText() -> String {
        let settings = AppSettings.shared
        let index = settings.nudgeDailyCount % nudgeTexts.count
        return nudgeTexts[index]
    }

    /// Zaehlt den Nudge fuer diesen Task hoch (nach Anzeige aufrufen).
    static func recordNudge(for taskID: String) {
        let settings = AppSettings.shared
        settings.nudgeDailyCount += 1

        var ids = settings.nudgeTaskIDs
            .split(separator: ",")
            .map(String.init)
            .filter { !$0.isEmpty }
        ids.append(taskID)
        settings.nudgeTaskIDs = ids.joined(separator: ",")
    }

    /// Reset bei neuem Tag (Mitternacht-Check).
    static func resetIfNewDay() {
        let settings = AppSettings.shared
        let today = isoDate()
        if settings.nudgeLastDate != today {
            settings.nudgeDailyCount = 0
            settings.nudgeTaskIDs = ""
            settings.nudgeLastDate = today
        }
    }

    // MARK: - Private

    private static func isoDate() -> String {
        let formatter = DateFormatter()
        formatter.dateFormat = "yyyy-MM-dd"
        return formatter.string(from: Date())
    }
}
```

private func startNudgeSprint(for task: LocalTask) {
    guard let repo = eventKitRepo else { return }
    Task {
        try? FocusBlockActionService.startImmediate(
            taskID: task.id,
            eventKitRepo: repo,
            modelContext: modelContext,
            durationMinutes: 2
        )

    }

### 6. FocusLiveView.swift — "Weitermachen?"-Dialog bei Nudge-Sprint-Ende

**Erkennung ob Nudge-Sprint:** Block-Dauer == 2 Minuten = Nudge-Sprint.

```swift
// Privates computed property:
private var isNudgeSprint: Bool {
    guard let block = currentBlock else { return false }
    let durationMinutes = Int(block.endDate.timeIntervalSince(block.startDate) / 60)
    return durationMinutes == 2
}
```

**Neuer State:**
```swift
@State private var showNudgeContinueDialog = false
```

**In checkBlockEnd() — nach bestehendem isPast-Check:**
```swift
if block.isPast {
    saveTaskTimes()
    playEndGong()

    if isNudgeSprint {
        // Weitermachen?-Dialog statt sofortigem SprintReview
        showNudgeContinueDialog = true
    } else {
        showSprintReview = true
    }
}
```

**confirmationDialog:**
```swift
.confirmationDialog(
    "Weitermachen?",
    isPresented: $showNudgeContinueDialog,
    titleVisibility: .visible
) {
    Button("Ja, weitermachen") {
        extendBlockToTaskDuration()
    }
    Button("Nein, beenden", role: .cancel) {
        showSprintReview = true
    }
} message: {
    Text("Du hast 2 Minuten gemacht. Willst du weitermachen?")
}
```

**extendBlockToTaskDuration():**
```swift
private func extendBlockToTaskDuration() {
    guard let block = currentBlock,
          let taskID = block.taskIDs.first,
          let task = fetchTask(id: taskID) else { return }

    let extraMinutes = task.estimatedDuration ?? 25
    let newEndDate = block.endDate.addingTimeInterval(Double(extraMinutes) * 60)
    block.endDate = newEndDate
    try? modelContext.save()

    // Timer neu starten mit neuer Endzeit
    restartTimer(until: newEndDate)
}
```

**Hinweis:** `restartTimer()` entspricht dem bestehenden Timer-Setup-Pattern in FocusLiveView. Die genaue Methode/Property wird bei Implementation nach bestehendem Code angepasst.

## Expected Behavior

- **Input:** Task hat rescheduleCount >= 3, Daily-Limits noch nicht erreicht
- **Output:**
  - In BacklogRow (iOS + macOS): Orange Dreieck-Badge sichtbar
  - In TaskDetailSheet: Nudge-Section mit Motivationstext + Button
  - Tap/Click startet 2-Min Focus Sprint
  - Nach 2 Min: "Weitermachen?"-Dialog
    - Ja: Block-Endzeit + Task-Schaetzung verlaengert, Timer laeuft weiter
    - Nein: Normales Sprint Review
- **Side effects:**
  - `EmotionalNudgeService.recordNudge()` wird nach Sprint-Start aufgerufen
  - `nudgeDailyCount` in AppSettings steigt um 1
  - `nudgeTaskIDs` in AppSettings erhaelt Task-ID (comma-appended)
  - Bei Ja: `block.endDate` wird veraendert + in ModelContext gespeichert

## Known Limitations

- Nudge-Erkennung via Block-Dauer (== 2 Min) ist heuristisch — falls User einen echten 2-Min Sprint plant, greift der Dialog faelschlicherweise
- AI-generierte Nudge-Texte (Story-Spec erwaehnt als Option) sind nicht implementiert — nur statische Liste
- "Weitermachen"-Verlaengerung nutzt `estimatedDuration` des Tasks als Standardwert; wenn nil, wird 25 Min als Fallback genutzt
- Kein Rollback wenn extendBlockToTaskDuration fehlschlaegt (Kalender-Event bleibt unveraendert)
