# RW_2.4 Backlog UX Rework — Implementation Spec (iOS)

## Approval

- [x] Approved

## Purpose

Ergaenzt die bestehende Story-Spec `docs/specs/rework/2.4-backlog-ux-rework.md` um konkrete Implementierungsdetails fuer iOS. Fuegt eine Parkdeck-Metapher zur `priorityView` hinzu: `doNow`- und `planSoon`-Tasks bleiben sichtbar, `eventually`- und `someday`-Tasks sowie manuell geparkte Tasks wandern in einen collapsed Bereich mit Badge-Count.

## Scope

**iOS only.** macOS (Context Menu, Sidebar) wird separat als `MAC_RW_2.4` umgesetzt.

## Source

- **File:** `Sources/Models/LocalTask.swift` — Model-Erweiterung
- **File:** `Sources/Models/PlanItem.swift` — isParked propagieren
- **File:** `Sources/Views/BacklogView.swift` — priorityView umbauen
- **File:** `FocusBloxUITests/BacklogParkdeckUITests.swift` — UI Tests (neu)

## Implementation Details

### 1. LocalTask.swift — isParked Feld

Neues Feld nach dem Block `// MARK: - Follow-up Chain (RW 3.3)` einfuegen:

```swift
// MARK: - Parkdeck (RW 2.4)

/// Manuell ins Parkdeck verschoben.
/// Tasks mit eventually/someday-Tier landen automatisch im Parkdeck.
/// isParked = true zwingt einen Task unabhaengig vom Score ins Parkdeck.
/// isParked = false + hoher Score = Task erscheint wieder in der Aktiv-Sektion.
var isParked: Bool = false
```

- CloudKit-kompatibel: `Bool` mit Default `false` (kein `?` noetig)
- SwiftData-Migration: Default-Wert reicht, kein `#Index`-Update noetig
- `init(...)` bekommt KEINEN `isParked`-Parameter (immer `false` bei Neuanlage)

---

### 2. PlanItem.swift — isParked propagieren

**a) Property deklarieren** (nach `let lifecycleStatus: String`):

```swift
/// Manuell ins Parkdeck verschoben (RW 2.4)
let isParked: Bool
```

**b) init(localTask:)** — Zuweisung hinzufuegen:

```swift
self.isParked = localTask.isParked
```

**c) init(reminder:)** — Reminders haben kein Parkdeck:

```swift
self.isParked = false
```

**d) Computed property fuer Parkdeck-Klassifikation** (Extension oder direkt auf PlanItem):

```swift
/// True wenn dieser Task im Parkdeck erscheinen soll.
/// Entweder manuell geparkt ODER Score-Tier ist eventually/someday.
var isInParkdeck: Bool {
    isParked || priorityTier == .eventually || priorityTier == .someday
}
```

> Hinweis: `priorityTier` ist bereits auf PlanItem definiert (Z.114-116 PlanItem.swift).

### 3. BacklogView.swift — priorityView umbauen

#### 3a. Neuer @State

```swift
@State private var isParkdeckExpanded: Bool = false
```

Platzierung: in der bestehenden `@State`-Gruppe (ca. Z.50-76).

#### 3b. Neue computed properties

```swift
/// Aktive Tasks: doNow + planSoon, nicht manuell geparkt, nicht ueberfaellig
private var activeTasks: [PlanItem] {
    backlogTasks
        .filter { !$0.isInParkdeck && !overdueTasks.contains(where: { $0.id == $1.id }) }
        .sorted { effectivePriorityScore(for: $0) > effectivePriorityScore(for: $1) }
}

/// Parkdeck-Tasks: eventually + someday + manuell geparkt
private var parkdeckTasks: [PlanItem] {
    backlogTasks
        .filter { $0.isInParkdeck }
        .sorted { effectivePriorityScore(for: $0) > effectivePriorityScore(for: $1) }
}
```

> `backlogTasks` ist bereits top-level-filtered (keine blocked Tasks, keine completed).
> `overdueTasks`-Filter gilt nur fuer activeTasks (Overdue-Section bleibt separat ganz oben).

#### 3c. priorityView ersetzen

Die bestehende `priorityView` (Z.1054-1119) wird umgebaut. Der `ForEach(PriorityTier.allCases)` Block entfaellt. Stattdessen:

```swift
private var priorityView: some View {
    List {
        nextUpListSection

        // --- Overdue (unveraendert) ---
        if !overdueTasks.isEmpty {
            Section { /* ... unveraendert ... */ } header: { /* ... unveraendert ... */ }
        }

        // --- Aktive Tasks (doNow + planSoon) ---
        if !activeTasks.isEmpty {
            Section {
                ForEach(activeTasks) { item in
                    backlogRowWithSwipe(item)
                        .swipeActions(edge: .trailing, allowsFullSwipe: false) {
                            // Bestehende trailing: Loeschen + Bearbeiten (unveraendert)
                            // Zusaetzlich: Parken-Action
                            Button {
                                parkTask(item)
                            } label: {
                                Label("Parken", systemImage: "car.fill")
                            }
                            .tint(.gray)
                        }
                }
            } header: {
                HStack {
                    Text("Aktive Tasks")
                        .font(.headline)
                        .foregroundStyle(.primary)
                    Spacer()
                    Text("\(activeTasks.count)")
                        .font(.caption)
                        .foregroundStyle(.secondary)
                        .padding(.horizontal, 6)
                        .padding(.vertical, 2)
                        .background(Color.secondary.opacity(0.15))
                        .clipShape(Capsule())
                }
                .accessibilityIdentifier("activeTasksSection")
            }
        }

        // --- Parkdeck (collapsed by default) ---
        Section {
            if isParkdeckExpanded {
                ForEach(parkdeckTasks) { item in
                    backlogRowWithSwipe(item)
                        .swipeActions(edge: .trailing, allowsFullSwipe: false) {
                            // Bestehende trailing: Loeschen + Bearbeiten (unveraendert)
                            // Zusaetzlich: Aktivieren-Action
                            Button {
                                activateTask(item)
                            } label: {
                                Label("Aktivieren", systemImage: "arrow.up.circle")
                            }
                            .tint(.blue)
                        }
                }
            }
        } header: {
            Button {
                withAnimation(.smooth) { isParkdeckExpanded.toggle() }
            } label: {
                HStack {
                    Image(systemName: isParkdeckExpanded ? "chevron.down" : "chevron.right")
                        .font(.caption)
                        .foregroundStyle(.secondary)
                    Text("Parkdeck")
                        .font(.headline)
                        .foregroundStyle(.secondary)
                    Spacer()
                    Text("\(parkdeckTasks.count)")
                        .font(.caption)
                        .foregroundStyle(.secondary)
                        .padding(.horizontal, 6)
                        .padding(.vertical, 2)
                        .background(Color.secondary.opacity(0.15))
                        .clipShape(Capsule())
                }
                .accessibilityIdentifier("parkdeckSection")
            }
            .buttonStyle(.plain)
        }
    }
    .listStyle(.plain)
    .scrollContentBackground(.hidden)
    .accessibilityIdentifier("backlogTaskList")
    .safeAreaInset(edge: .bottom, spacing: 0) { Color.clear.frame(height: 120) }
    .refreshable { await loadTasks() }
}
```

> **Lazy Loading:** Parkdeck-Tasks werden nur via `if isParkdeckExpanded` gerendert — SwiftUI rendert den `ForEach`-Inhalt nicht, solange der Block `false` ist.

#### 3d. Swipe-Action Helper-Methoden (neue private funcs)

```swift
/// Setzt isParked = true auf LocalTask (Task wandert ins Parkdeck)
private func parkTask(_ item: PlanItem) {
    guard let task = findLocalTask(id: item.id) else { return }
    task.isParked = true
    task.modifiedAt = Date()
    try? modelContext.save()
    Task { await loadTasks() }
}

/// Setzt isParked = false auf LocalTask (Task wird nach Score einsortiert)
private func activateTask(_ item: PlanItem) {
    guard let task = findLocalTask(id: item.id) else { return }
    task.isParked = false
    task.modifiedAt = Date()
    try? modelContext.save()
    Task { await loadTasks() }
}
```

> `findLocalTask(id:)` ist ein bereits existierender Helper in BacklogView.swift.

#### 3e. Suchfunktion — keine Aenderung noetig

`matchesSearch()` arbeitet auf `planItems` (das vollstaendige Array). `backlogTasks` filtert bereits via `allBacklogTasks` mit `matchesSearch($0)` (Z.97). Damit durchsucht die Suche automatisch alle Tasks inkl. Parkdeck-Tasks, unabhaengig von `isParkdeckExpanded`.

### 4. Swipe-Action Reihenfolge

**Aktive Tasks (trailing):**
1. Loeschen (destructive, rot) — unveraendert
2. Bearbeiten (blau) — unveraendert
3. Parken (grau, `car.fill`) — NEU

**Parkdeck-Tasks (trailing):**
1. Loeschen (destructive, rot) — unveraendert
2. Bearbeiten (blau) — unveraendert
3. Aktivieren (blau, `arrow.up.circle`) — NEU

**Leading Swipe (beide Sektionen):** unveraendert — "Next Up" (gruen)

> Hinweis: `backlogRowWithSwipe()` definiert bereits Leading- und Trailing-Actions. Zusaetzliche Trailing-Actions werden mit einem weiteren `.swipeActions(edge: .trailing)` Modifier ergaenzt — iOS stapelt mehrere `.swipeActions` auf derselben Edge.

## Expected Behavior

- **Input:** Backlog mit gemischten Tasks verschiedener PriorityTier-Stufen
- **Output:**
  - `priorityView` zeigt "Aktive Tasks" Section (doNow + planSoon, nicht geparkt)
  - Darunter "Parkdeck" Section mit Badge (initially collapsed)
  - Tap auf Parkdeck-Header expandiert/collapsed die Liste
  - Swipe Trailing auf aktivem Task: "Parken"-Action verfuegbar
  - Swipe Trailing auf Parkdeck-Task: "Aktivieren"-Action verfuegbar
  - Suche ignoriert collapsed-Status des Parkdecks
- **Side effects:**
  - `parkTask()` setzt `isParked = true` + `modifiedAt` + speichert
  - `activateTask()` setzt `isParked = false` + `modifiedAt` + speichert
  - `@AppStorage` oder `@State` fuer `isParkdeckExpanded` — wird NICHT persisted (reset nach App-Neustart = collapsed, by design)

## Known Limitations

- `isParkdeckExpanded` ist `@State`, nicht `@AppStorage` — collapsed nach App-Restart (by design: Parkdeck-Status ist transient, kein Speicherbedar)
- Tasks mit `isTbd: true` (fehlende Felder) koennen Score 0-9 haben und landen im Parkdeck (someday) — das ist korrekt
- `backlogRowWithSwipe()` kann nicht einfach mit einem anderen Trailing-Action-Set aufgerufen werden; stattdessen wird ein zusaetzlicher `.swipeActions`-Modifier nachgelagert angehaengt. iOS stapelt diese korrekt.
- macOS: Dieses Ticket enthaelt keine macOS-Aenderungen (kein Context Menu, keine Sidebar-Badge). Folgt in MAC_RW_2.4.
