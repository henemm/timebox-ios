## Implementation Details

### 1. ScheduledTaskBlock.swift (CREATE, ~50 LoC)

Neue shared View fuer beide Timeline-Kontexte (PlanningView + BlockPlanningView).

```swift
struct ScheduledTaskBlock: View {
    let taskID: String
    let title: String
    let startDate: Date
    let endDate: Date
    let onUnschedule: () -> Void
    let onStartFocusSprint: (() -> Void)?

    var body: some View {
        HStack(spacing: 8) {
            // Orange Sidebar-Accent (4px)
            RoundedRectangle(cornerRadius: 2)
                .fill(.orange)
                .frame(width: 4)

            VStack(alignment: .leading, spacing: 2) {
                Text(title)
                    .font(.subheadline.bold())
                    .foregroundStyle(.primary)
                    .lineLimit(1)
                Text(timeRangeText)
                    .font(.caption2)
                    .foregroundStyle(.secondary)
            }

            Spacer()

            Image(systemName: "calendar.badge.clock")
                .font(.caption)
                .foregroundStyle(.orange)
        }
        .padding(.vertical, 6)
        .padding(.horizontal, 8)
        .background(
            RoundedRectangle(cornerRadius: 8)
                .fill(.orange.opacity(0.1))
        )
        .overlay(
            RoundedRectangle(cornerRadius: 8)
                .strokeBorder(.orange.opacity(0.3), lineWidth: 1)
        )
        .contentShape(Rectangle())
        .contextMenu {
            if let onSprint = onStartFocusSprint {
                Button {
                    onSprint()
                } label: {
                    Label("Focus Sprint starten", systemImage: "bolt.fill")
                }
                Divider()
            }
            Button(role: .destructive) {
                onUnschedule()
            } label: {
                Label("Entplanen", systemImage: "arrow.uturn.backward")
            }
        }
        .accessibilityIdentifier("scheduledTaskBlock_\(taskID)")
    }

    private var timeRangeText: String {
        let formatter = DateFormatter()
        formatter.timeStyle = .short
        return "\(formatter.string(from: startDate)) – \(formatter.string(from: endDate))"
    }
}
```

**Design-Entscheidungen:**
- Orange Sidebar-Accent (4px) — visuell unterscheidbar von EventBlock (vollflaechig) und FocusBlock (blau)
- Title in `.primary` (nicht orange) — besser lesbar als Phase B Platzhalter
- Zeitrange anzeigen (wie EventBlock) — in Phase B fehlte das noch
- `calendar.badge.clock` Icon rechts — zeigt "geplanter Task" vs. "Event" vs. "FocusBlock"
- Context Menu statt confirmationDialog — natuerlichere Interaktion, konsistent mit NextUpSection

## Expected Behavior

- **Visuell:** Geplante Tasks auf der Timeline haben eigenes Design — orange Sidebar-Accent, Title, Zeitrange, Clock-Icon
- **Context Menu:** Long-Press auf ScheduledTaskBlock zeigt "Focus Sprint starten" + "Entplanen"
- **Entplanen:** Task kehrt in MiniBacklog/Backlog zurueck (scheduledDate = nil via SyncEngine)
- **Focus Sprint:** Startet FocusBlock sofort via FocusBlockActionService.startImmediate
- **Side effects:** Keine neue Business-Logik — nur UI-Aenderung auf bestehender Phase B Infrastruktur

## Business Rules

1. **Context Menu immer sichtbar:** Entplanen ist immer verfuegbar. Focus Sprint nur wenn FocusBlockActionService verfuegbar (immer auf iOS, Callback optional fuer Testbarkeit).
2. **Kein Doppel-Dialog:** confirmationDialog fuer scheduled Tasks wird komplett entfernt — Context Menu ersetzt es.
3. **Accessibility:** `scheduledTaskBlock_\(taskID)` Identifier bleibt gleich wie in Phase B — UI Tests muessen nicht angepasst werden.
