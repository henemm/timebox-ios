# RW_3.1d — GapFinder + Notifications + macOS

## Purpose

Schliesst die Calendar Task Drop Story ab: GapFinder erkennt Scheduled Tasks als belegte Slots, Notification-Reconciliation wird bei Schedule-Aenderungen getriggert, und macOS rendert Scheduled Tasks auf der Timeline mit Drop-to-Schedule.

## Implementation Details

### 1. GapFinder.swift (MODIFY, ~15 LoC)

Neuer Parameter fuer Scheduled Tasks als belegte Zeitslots.

**Aendern:**
```swift
struct GapFinder {
    let events: [CalendarEvent]
    let focusBlocks: [FocusBlock]
    let scheduledTasks: [(start: Date, end: Date)]  // NEU
    let date: Date
    // ...
}
```

**In `findFreeSlots()`:** Scheduled Tasks in busyPeriods einfuegen (nach focusBlocks-Loop):
```swift
for task in scheduledTasks {
    busyPeriods.append((task.start, task.end))
}
```

**Caller anpassen** (2 Stellen):
- `Sources/Views/BlockPlanningView.swift`: computedFreeSlots — scheduledTasks als Tupel-Array uebergeben
- `FocusBloxMac/MacPlanningView.swift`: computedFreeSlots — gleiches Pattern

**Design-Entscheidung:** Tupel `(start: Date, end: Date)` statt `[TimelineItem]` — GapFinder soll kein UI-Model importieren muessen. Leichtgewichtig, einfach zu testen.

### 2. PlanningView.swift (MODIFY, ~10 LoC)

**Aendern:** In `scheduleTask()` und `unscheduleTask()` nach dem SyncEngine-Aufruf Notification-Reconciliation triggern:

```swift
private func scheduleTask(_ transfer: PlanItemTransfer, at startTime: Date) {
    Task {
        do {
            let taskSource = LocalTaskSource(modelContext: modelContext)
            let syncEngine = SyncEngine(taskSource: taskSource, modelContext: modelContext)
            try syncEngine.scheduleTask(itemID: transfer.id, date: startTime, duration: transfer.duration)
            await SmartNotificationEngine.reconcile(
                reason: .taskChanged, context: modelContext, eventKitRepo: eventKitRepo
            )
            await loadData()
        } catch { /* existing error handling */ }
    }
}
```

Gleiches Pattern fuer `unscheduleTask()`.

### 4. MacPlanningView.swift (MODIFY, ~40 LoC)

**Neue State-Variable:**
```swift
@State private var scheduledTasks: [TimelineItem] = []
```

**Scheduled Tasks laden** (in `loadCalendarEvents()` oder eigene Methode):
```swift
private func loadScheduledTasks() {
    let calendar = Calendar.current
    let dayStart = calendar.startOfDay(for: selectedDate)
    let dayEnd = calendar.date(byAdding: .day, value: 1, to: dayStart)!

    let descriptor = FetchDescriptor<LocalTask>(
        predicate: #Predicate<LocalTask> {
            !$0.isCompleted && $0.scheduledDate != nil
        }
    )
    guard let allTasks = try? modelContext.fetch(descriptor) else { return }

    scheduledTasks = allTasks
        .filter { $0.scheduledDate! >= dayStart && $0.scheduledDate! < dayEnd }
        .map { TimelineItem(
            scheduledTaskID: $0.id,
            title: $0.title,
            scheduledDate: $0.scheduledDate!,
            durationMinutes: $0.scheduledDuration ?? $0.estimatedDuration ?? 30
        )}
}
```

**An MacTimelineView durchreichen:**
```swift
MacTimelineView(
    date: selectedDate,
    events: calendarEvents,
    focusBlocks: focusBlocks,
    scheduledTasks: scheduledTasks,    // NEU
    freeSlots: computedFreeSlots,
    // ... bestehende Callbacks ...
    onScheduleTask: { task, time in    // NEU
        scheduleTaskOnMac(task, at: time)
    },
    onUnscheduleTask: { taskID in      // NEU
        unscheduleTaskOnMac(taskID)
    },
    onStartFocusSprint: { taskID in    // NEU
        startFocusSprintOnMac(taskID)
    }
)
```

**Neue Methoden:**
```swift
private func scheduleTaskOnMac(_ task: MacTaskTransfer, at time: Date) {
    Task {
        let taskSource = LocalTaskSource(modelContext: modelContext)
        let syncEngine = SyncEngine(taskSource: taskSource, modelContext: modelContext)
        try? syncEngine.scheduleTask(itemID: task.id, date: time, duration: task.duration)
        await SmartNotificationEngine.reconcile(
            reason: .taskChanged, context: modelContext, eventKitRepo: eventKitRepo
        )
        loadScheduledTasks()
    }
}

private func unscheduleTaskOnMac(_ taskID: String) {
    Task {
        let taskSource = LocalTaskSource(modelContext: modelContext)
        let syncEngine = SyncEngine(taskSource: taskSource, modelContext: modelContext)
        try? syncEngine.unscheduleTask(itemID: taskID)
        await SmartNotificationEngine.reconcile(
            reason: .taskChanged, context: modelContext, eventKitRepo: eventKitRepo
        )
        loadScheduledTasks()
    }
}
```

## Expected Behavior

- **GapFinder:** Zeitslots die durch Scheduled Tasks belegt sind werden NICHT als freie Slots vorgeschlagen
- **Notifications:** Nach Schedule/Unschedule werden Notifications sofort rekalibriert (reconcile)
- **macOS Timeline:** Scheduled Tasks erscheinen als orange ScheduledTaskBlock mit Context Menu (Entplanen, Focus Sprint)
- **macOS Drop:** Task aus Next Up auf Timeline droppen = Task einplanen (nicht FocusBlock erstellen). Drop auf FocusBlock = Task dem Block zuweisen (wie bisher)
- **Side effects:** GapFinder-Aenderung wirkt sich auf BEIDE Plattformen aus — iOS FreeSlots werden ebenfalls korrekt berechnet

## Business Rules

1. **Default-Drop = Task einplanen:** Konsistent mit iOS. FocusBlock-Erstellung bleibt ueber Free Slots erreichbar.
2. **Mutual Exclusion bleibt:** Task kann nicht gleichzeitig scheduled UND in einem FocusBlock sein (SyncEngine regelt das bereits).
3. **GapFinder ist lightweight:** Nur Tupel-Input, kein LocalTask-Import. Einfach testbar.
4. **Reconciliation ist fire-and-forget:** View ruft reconcile auf, wartet nicht auf Ergebnis fuer UI-Update.
