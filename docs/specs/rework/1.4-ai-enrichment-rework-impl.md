## Kontext

Die aktuelle TaskTitleEngine nutzt Apple Intelligence (On-Device 3B Modell) um Task-Titel zu "bereinigen". Tests haben gezeigt:

- **Titel-Bereinigung durch AI: ~30% korrekt** — Umlaute werden konvertiert (fuer statt fuer), Sonderzeichen zerstoert (& wird zu sse), Woerter gehen verloren, ~50% der Inputs loesen Apples Safety Guardrails aus
- **Kategorisierung durch AI: 88% korrekt** — 5 Kategorien mit @Guide(.anyOf()) Constraints
- **Zeitschaetzung durch AI: 75% korrekt** — 4er-Raster (5/15/30/60 min) mit @Guide(.anyOf()) Constraints

Testdaten und Ergebnisse: `FocusBloxTests/AITitleQualityTests.swift`

## Entscheidung

| Bereich | Bisher | Neu |
|---------|--------|-----|
| Titel-Cleanup | AI (produziert Quatsch) | Deterministisch (Regex) |
| Kategorisierung | Keine | AI mit @Guide(.anyOf()) |
| Zeitschaetzung | Keine | AI mit @Guide(.anyOf(["5","15","30","60"])) |
| Datum/Dringlichkeit | Teilweise AI | Komplett deterministisch (bleibt) |

## Implementierung

### 1. ENTFERNEN aus TaskTitleEngine.swift

- `ImprovedTask` @Generable Struct (der kaputte deutsche Prompt)
- `performImprovement()` (AI-Titel-Rewriting)
- `shouldAcceptImprovedTitle()` (Safety Guard — nicht mehr noetig)

### 2. HINZUFUEGEN

#### 2a. `cleanTitle()` — Deterministisch

Statische Methode die per Regex bereinigt:
- E-Mail-Prefixe entfernen: `Re:`, `Fwd:`, `AW:`, `WG:`, `FW:` (case-insensitive)
- Einleitungsfloskeln entfernen: "Erinnere mich daran", "Ich muss noch", "Vergiss nicht", "Denk daran"
- Urgency-Keywords entfernen (bestehende `stripKeywords()` integrieren)
- Whitespace normalisieren
- Umlaute und Sonderzeichen werden NIE angefasst

#### 2b. `TaskSuggestion` @Generable Struct

```swift
@Generable
struct TaskSuggestion {
    @Guide(description: "Task category", .anyOf(["income", "maintenance", "recharge", "learning", "giving_back"]))
    let category: String

    @Guide(description: "Estimated duration in minutes", .anyOf(["5", "15", "30", "60"]))
    let estimatedMinutes: String
}
```

Prompt (englisch, kurz):
```
"Categorize tasks and estimate duration."
"Categories: income (work/career/money), maintenance (household/errands/health), recharge (exercise/hobbies/rest), learning (study/reading/courses), giving_back (family/friends/social)"
"Duration: 5 (quick call/message), 15 (short errand), 30 (medium task), 60 (long/deep work)"
```

#### 2c. `enrichWithSuggestions()` — Neue oeffentliche API

1. `cleanTitle()` ausfuehren (deterministisch, sofort)
2. Datum/Urgency deterministisch extrahieren (bestehende Logik)
3. Falls AI verfuegbar: `TaskSuggestion` generieren lassen
4. Ergebnisse in `task.suggestedCategory` und `task.suggestedDuration` schreiben
5. `task.needsTitleImprovement = false` setzen

### 3. BEIBEHALTEN (unveraendert)

- `stripKeywords()`
- `titleContainsDateKeyword()`
- `extractDeterministicDueDate()`
- `relativeDateFrom()`
- `nextWeekday()`

### 4. BACKWARD-KOMPATIBILITAET

`improveTitleIfNeeded()` bleibt als oeffentliche API erhalten — ruft intern `cleanTitle()` + `enrichWithSuggestions()` auf. Alle Aufrufer (LocalTaskSource, FocusBloxApp) funktionieren ohne Aenderung.

## Acceptance Criteria

1. **Titel werden NIE durch AI veraendert** — nur deterministisch per Regex
2. **Umlaute und Sonderzeichen bleiben IMMER erhalten**
3. **AI schlaegt Kategorie vor** — Wert in `suggestedCategory`, User kann ueberschreiben
4. **AI schlaegt Dauer vor** — Wert in `suggestedDuration` (5/15/30/60), User kann ueberschreiben
5. **Deterministische Tests fuer cleanTitle()**: E-Mail-Artefakte, Floskeln, Urgency, Umlaut-Erhaltung
6. **AI-Tests fuer Kategorisierung**: mind. 80% korrekt (bestehende Test-Matrix)
7. **AI-Tests fuer Zeitschaetzung**: mind. 70% korrekt (bestehende Test-Matrix)
8. **Build erfolgreich** auf iOS und macOS (`sim.sh build` + `sim.sh mac-build`)

## Risiken

- **guardrailViolation**: ~10-15% der Inputs loesen Apples Safety Filter aus. Fallback: kein Vorschlag, User waehlt manuell. Kein Datenverlust.
- **@Guide(.anyOf())** Syntax ist getestet und funktioniert mit iOS 26.2 SDK.
