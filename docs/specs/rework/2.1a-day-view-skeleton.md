## Implementation Details

### DayPhase Enum (in DayView.swift)

```swift
enum DayPhase {
    case morning   // hour < morningEndHour (default 12)
    case daytime   // morningEndHour <= hour < eveningStartHour (default 18)
    case evening   // hour >= eveningStartHour

    static func current(morningEnd: Int, eveningStart: Int) -> DayPhase {
        let hour = Calendar.current.component(.hour, from: Date())
        if hour < morningEnd { return .morning }
        if hour < eveningStart { return .daytime }
        return .evening
    }
}
```

### DayView (shared, Sources/Views/)

```swift
struct DayView: View {
    @AppStorage("morningEndHour") private var morningEndHour = 12
    @AppStorage("eveningStartHour") private var eveningStartHour = 18

    private var phase: DayPhase {
        DayPhase.current(morningEnd: morningEndHour, eveningStart: eveningStartHour)
    }

    var body: some View {
        NavigationStack {
            // Switch auf phase → Platzhalter pro Modus
        }
        .navigationTitle(navigationTitle)
    }
}
```

### Platzhalter-Content pro Modus

- **Morning:** SF Symbol `sunrise` + "Guten Morgen" + Text "Kalender-Uebersicht kommt bald"
- **Daytime:** SF Symbol `sun.max` + "Dein Tag" + Text "Timeline kommt bald"
- **Evening:** SF Symbol `moon.stars` + "Tagesrueckblick" + Text "Reflexion kommt bald"

Jeder Modus zeigt ein grosses zentriertes Icon mit Titel und Untertitel — ContentUnavailableView Pattern.

## Expected Behavior

- **Input:** Uhrzeit des Geraets
- **Output:** DayView zeigt passenden Modus-Platzhalter
- **Side effects:** Keine — Phase A laedt keine Daten, kein EventKit, kein BehavioralProfile

### Modi-Wechsel
| Uhrzeit | Phase | Titel | Icon |
|---------|-------|-------|------|
| 00:00 - 11:59 | morning | "Guten Morgen" | sunrise |
| 12:00 - 17:59 | daytime | "Dein Tag" | sun.max |
| 18:00 - 23:59 | evening | "Tagesrueckblick" | moon.stars |

### Navigation
- iOS: Tab "Tag" zwischen "Blox" und "Focus"
- macOS: Sidebar-Eintrag "Tag" zwischen "Blox" und "Focus", DayView als Content-Area

- Settings-UI fuer morningEndHour/eveningStartHour noch nicht vorhanden (kommt spaeter)
- Modi-Wechsel ist nicht live-animiert (View aktualisiert sich beim naechsten Rendern)
