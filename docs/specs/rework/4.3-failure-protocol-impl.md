# RW_4.3 — Failure Protocol

## Purpose

Optionales Quick-Select im Abend-Modus der DayView: Warum wurde ein Task nicht erledigt? 6 vordefinierte Gruende (noTime, tooTired, blocked, notRelevant, forgotAboutIt, other), historisiert als SwiftData Records. ### 1. TaskFailureRecord.swift — SwiftData Model

```swift
import Foundation
import SwiftData

/// Grund warum ein Task nicht erledigt wurde.
/// Als String gespeichert fuer CloudKit-Kompatibilitaet.
enum FailureReason: String, Codable, CaseIterable {
    case noTime        // "Keine Zeit"
    case tooTired      // "Zu muede"
    case blocked       // "Blockiert"
    case notRelevant   // "Nicht mehr relevant"
    case forgotAboutIt // "Vergessen"
    case other         // "Anderer Grund"

    var displayName: String {
        switch self {
        case .noTime:        "Keine Zeit"
        case .tooTired:      "Zu muede"
        case .blocked:       "Blockiert"
        case .notRelevant:   "Nicht relevant"
        case .forgotAboutIt: "Vergessen"
        case .other:         "Anderes"
        }
    }

    var systemImage: String {
        switch self {
        case .noTime:        "clock"
        case .tooTired:      "battery.25percent"
        case .blocked:       "xmark.octagon"
        case .notRelevant:   "arrow.uturn.backward"
        case .forgotAboutIt: "questionmark.circle"
        case .other:         "ellipsis.circle"
        }
    }
}

@Model
final class TaskFailureRecord {
    #Index<TaskFailureRecord>([\.date], [\.reasonRaw])

    var taskID: String = ""
    var date: Date = Date()
    var reasonRaw: String = FailureReason.other.rawValue

    var reason: FailureReason {
        get { FailureReason(rawValue: reasonRaw) ?? .other }
        set { reasonRaw = newValue.rawValue }
    }

    init(taskID: String, date: Date, reason: FailureReason) {
        self.taskID = taskID
        self.date = date
        self.reasonRaw = reason.rawValue
    }
}
```

**Wichtig:**
- `reasonRaw` als String (CloudKit kann keine Swift-Enums)
- Computed `reason` Property fuer typsicheren Zugriff
- Alle Attribute haben Default-Werte (CloudKit-Pflicht)
- `#Index` auf `date` und `reasonRaw` fuer Performance

### 2. FailureProtocolService.swift — Service

```swift
import Foundation
import SwiftData

enum FailureProtocolService {

    /// Speichert einen Failure-Record. Append-only, nie loeschen.
    /// Prueft Duplikate: gleicher taskID + gleiches Datum = kein Insert.
    static func save(
        taskID: String,
        reason: FailureReason,
        context: ModelContext,
        date: Date = Date()
    ) {
        let startOfDay = Calendar.current.startOfDay(for: date)
        let endOfDay = Calendar.current.date(byAdding: .day, value: 1, to: startOfDay)!

        // Duplikat-Check: gleicher Task am gleichen Tag?
        let descriptor = FetchDescriptor<TaskFailureRecord>(
            predicate: #Predicate<TaskFailureRecord> { record in
                record.taskID == taskID &&
                record.date >= startOfDay &&
                record.date < endOfDay
            }
        )
        let existing = (try? context.fetch(descriptor)) ?? []
        guard existing.isEmpty else { return }

        let record = TaskFailureRecord(taskID: taskID, date: date, reason: reason)
        context.insert(record)
        try? context.save()
    }

    /// Holt alle Failure-Records fuer ein bestimmtes Datum.
    static func fetchForDate(
        _ date: Date,
        context: ModelContext
    ) -> [TaskFailureRecord] {
        let startOfDay = Calendar.current.startOfDay(for: date)
        let endOfDay = Calendar.current.date(byAdding: .day, value: 1, to: startOfDay)!

        let descriptor = FetchDescriptor<TaskFailureRecord>(
            predicate: #Predicate<TaskFailureRecord> { record in
                record.date >= startOfDay && record.date < endOfDay
            }
        )
        return (try? context.fetch(descriptor)) ?? []
    }
}
```

### 3. FailureQuickSelectView.swift — UI

```swift
import SwiftUI
import SwiftData

struct FailureQuickSelectView: View {
    let task: PlanItem
    @Environment(\.modelContext) private var modelContext
    @State private var selectedReason: FailureReason?
    @State private var dismissed = false

    var body: some View {
        if !dismissed {
            VStack(alignment: .leading, spacing: 8) {
                HStack {
                    Text(task.title)
                        .font(.subheadline)
                        .fontWeight(.medium)
                        .lineLimit(1)
                    Spacer()
                    Button {
                        dismissed = true
                    } label: {
                        Image(systemName: "xmark")
                            .font(.caption)
                            .foregroundStyle(.secondary)
                    }
                    .accessibilityIdentifier("failureDismiss_\(task.id)")
                }

                Text("Woran lag's?")
                    .font(.caption)
                    .foregroundStyle(.secondary)

                FlowLayout(spacing: 6) {
                    ForEach(FailureReason.allCases, id: \.self) { reason in
                        Button {
                            selectedReason = reason
                            FailureProtocolService.save(
                                taskID: task.id,
                                reason: reason,
                                context: modelContext
                            )
                        } label: {
                            Label(reason.displayName, systemImage: reason.systemImage)
                                .font(.caption)
                                .padding(.horizontal, 10)
                                .padding(.vertical, 6)
                                .background(
                                    selectedReason == reason
                                        ? Color.accentColor.opacity(0.2)
                                        : Color(.systemFill),
                                    in: Capsule()
                                )
                        }
                        .buttonStyle(.plain)
                        .accessibilityIdentifier("failureReason_\(reason.rawValue)")
                    }
                }
            }
            .padding()
            .background(.regularMaterial, in: RoundedRectangle(cornerRadius: 12))
            .accessibilityElement(children: .contain)
            .accessibilityIdentifier("failureQuickSelect_\(task.id)")
        }
    }
}
```

## Expected Behavior

- **Input:** `unfinishedTasks: [PlanItem]` (bereits in loadEveningData() geladen), `modelContext`
- **Output:** Pro unerledgtem Task eine Card mit 6 Reason-Buttons + Dismiss-Button
- **Side effects:**
  - `TaskFailureRecord` wird in SwiftData gespeichert (CloudKit sync)
  - Append-only: Records werden nie geloescht
  - Duplikat-Prevention: gleicher Task + gleiches Datum = kein zweiter Record

**User Flow:**
1. User oeffnet DayView im Abend-Modus (ab 18:00 oder konfiguriert)
2. Unter der Success Story sieht er pro unerledgtem Task eine Card: "Woran lag's?"
3. Optional: Tippt auf einen der 6 Gruende → Button wird hervorgehoben, Record wird gespeichert
4. Optional: Tippt auf X → Card wird ausgeblendet (kein Record gespeichert)
5. Kein Zwang — Cards sind wegwischbar und optional

**Accessibility:**
- Card-Container: `failureQuickSelect_<taskID>`
- Dismiss-Button: `failureDismiss_<taskID>`
- Reason-Buttons: `failureReason_<reasonRawValue>` (z.B. `failureReason_noTime`)

## Known Limitations

- BehavioralProfileService-Integration bewusst auf RW_4.3b verschoben — Daten werden gespeichert aber noch nicht ausgewertet
- NextUpSuggestionService existiert noch nicht — Failure-basierte Filter kommen mit RW_2.2
- Keine aggregierte Statistik ("Haeufigste Gruende diese Woche") — kommt mit RW_4.3b
- `FlowLayout` muss existieren — Fallback auf LazyVGrid falls nicht vorhanden
- Dismissed-State ist ephemeral (@State) — nach App-Neustart sind Cards wieder sichtbar (nur wenn kein Record fuer den Task existiert, werden sie angezeigt)
