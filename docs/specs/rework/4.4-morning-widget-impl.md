# RW_4.4 Morning Widget (DayStatusWidget)

## Approval

- [x] Approved

## Purpose

Lock Screen Widget das den Tagesstatus in zwei zeitbasierten Modi anzeigt: morgens die Anzahl wartender Tasks und die aelteste Aufgabe, abends eine Abschluss-Quote. Es motiviert zur Tagesplanung und gibt einen schnellen Ueberblick ohne die App oeffnen zu muessen.

## Implementation Details

### App Group Keys (UserDefaults)

```swift
// Suite: UserDefaults(suiteName: "group.com.henning.focusblox")
"widget_nextUpCount"         // Int — Tasks in Next Up, nicht completed
"widget_completedTodayCount" // Int — completedAt >= startOfDay
"widget_totalTodayCount"     // Int — nextUpCount + completedTodayCount
"widget_oldestWaitingDays"   // Int — max Tage seit createdAt fuer unfinished Next Up
"widget_lastUpdated"         // TimeInterval — Date().timeIntervalSince1970
```

### WidgetDataPublisher (CREATE ~55 LoC)

```swift
// Sources/Services/WidgetDataPublisher.swift
// #if canImport(WidgetKit) guard fuer mac-build-Kompatibilitaet

enum WidgetDataPublisher {
    static let appGroupID = "group.com.henning.focusblox"

    /// Publishes aggregated task data to App Group UserDefaults for widget consumption.
    /// Must be called from main app context where ModelContext is available.
    static func publish(context: ModelContext) {
        guard let defaults = UserDefaults(suiteName: appGroupID) else { return }

        let today = Calendar.current.startOfDay(for: Date())
        let allTasks = (try? context.fetch(FetchDescriptor<LocalTask>())) ?? []

        let nextUp = allTasks.filter { !$0.isCompleted && $0.isNextUp }
        let completedToday = allTasks.filter {
            guard let completedAt = $0.completedAt else { return false }
            return completedAt >= today
        }
        let oldestDays = nextUp.compactMap { task -> Int? in
            guard let created = task.createdAt else { return nil }
            return Calendar.current.dateComponents([.day], from: created, to: Date()).day
        }.max() ?? 0

        defaults.set(nextUp.count, forKey: "widget_nextUpCount")
        defaults.set(completedToday.count, forKey: "widget_completedTodayCount")
        defaults.set(nextUp.count + completedToday.count, forKey: "widget_totalTodayCount")
        defaults.set(oldestDays, forKey: "widget_oldestWaitingDays")
        defaults.set(Date().timeIntervalSince1970, forKey: "widget_lastUpdated")

        #if canImport(WidgetKit)
        import WidgetKit
        WidgetCenter.shared.reloadTimelines(ofKind: DayStatusWidget.kind)
        #endif
    }
}
```

### DayStatusWidget TimelineProvider (~155 LoC total)

Timeline-Eintraege: 3 pro Tag — **07:00, 12:00, 18:00**

```
Entry 1 (07:00–11:59): MORNING Modus
Entry 2 (12:00–17:59): MORNING Modus (uebergang)
Entry 3 (18:00–23:59): EVENING Modus
```

**MORNING Modus (vor 12:00):**
- Primaertext: `"X Tasks warten"`
- Sekundaertext: `"Aelteste seit Y Tagen"` (nur wenn Y > 0)
- Wenn keine Tasks: `"Alles erledigt"`

**EVENING Modus (ab 18:00):**
- Primaertext: `"X von Y geschafft heute"`
- Emoji wenn Quote >= 50%: ✓ (checkmark) — kein negatives Feedback
- Wenn total == 0: `"Freier Tag"`

## Expected Behavior

- **Input:** Aktuelle Task-Liste aus App Group UserDefaults (geschrieben von WidgetDataPublisher)
- **Output:** Lock Screen Widget mit zeitbasiertem Text (Morgen/Abend-Modus)
- **Side effects:**
  - Tap auf Widget oeffnet App und navigiert direkt zu DayView (AppTab.day)
  - WidgetDataPublisher.publish() wird bei App-Lifecycle-Events und nach completeTask() aufgerufen
  - Timeline wird automatisch um 07:00, 12:00 und 18:00 Uhr erneuert

## Known Limitations

- Freie Stunden (GapFinder) entfallen in V1 — benoetigt EventKit-Integration (zukunftig)
- Widget zeigt nur `nextUp`-Bucket Tasks, keine anderen Buckets
- mac-build: `WidgetKit` wird mit `#if canImport(WidgetKit)` gegattet — macOS zeigt kein Widget
- Daten koennen bis zu einer Stunde veraltet sein, wenn weder App-Lifecycle noch completeTask() ausgeloest wird
- Keine Echtzeit-Updates — nur bei den drei Timeline-Eintraegen + explizitem reload
